Sea service report (PDF)

Evidence: AMSA's near coastal sea service guidance lists a Record of sea service (form 771), its sea service letter template signed by a supervisor, operator, owner, master or chief engineer, or an AMSA-approved task book. Some certificate pages also mention an approved sea service log book; this app is not AMSA-approved. Use Form 771 sheets (one page per vessel, duty and operation type) to complete the 771s for signature, and the Logbook PDF as the supporting record.

Creates a PDF file and downloads it (on iPhone/iPad it opens in the viewer, then use the share icon → Save to Files). Includes blank lines for you and your supervisor to sign and date. The PDF library downloads once, then works offline.

How sea days are counted

Per AMSA near coastal rules: one day of sea service = 8 hours of work relevant to the certificate. Shifts shorter than 8 hours are added together (partial days are summed and shown as fractions, e.g. 0.3 of a day); more than 8 hours in a 24-hour period still counts as one day only. Time when the vessel is not underway (and not at anchor with someone on watch) is counted separately because AMSA caps it at 15% of the service required for a deck certificate (33% for engineering).

Import from spreadsheet

Bring in past records from Excel (.xlsx, .xls) or CSV. You choose which of your columns match which logbook fields, then check a preview before anything is added.

Excel files need an internet connection the first time to load the reader. CSV works offline.

Bulk edit

Change one field on many entries at once. Period summaries are left alone. Take a backup first if you're unsure (sync history on GitHub also lets you roll back).

Sync between devices (GitHub)

Keeps your logbook in a private GitHub repository so your phone and laptop stay in step. It works offline and syncs when you're online. Every sync is a commit, so GitHub keeps the full history.

Set-up steps
  1. On github.com create a new private repository (for example vessel-logbook-data) and tick "Add a README file".
  2. Go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories → that repository. Permissions → Repository permissions → Contents: Read and write. Pick an expiry (the maximum is 1 year).
  4. Copy the token and paste it below, with the repository as owner/name, then tap Connect.
  5. Set up your device that already has your data first. On other devices, connect before entering data, so records aren't duplicated.

The token is stored only on this device (never in the repository or in backups). The app refuses to connect to a public repository.

Backup

Data is stored only on this device. If you clear browser data or lose the device it is gone, so export a backup regularly.
